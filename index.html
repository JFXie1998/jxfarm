柚子不是「糖水」，它其实挺克制

水果的甜主要来自果糖和葡萄糖。柚子的特点是水分大、单位热量低， 酸甜感又明显，所以吃同样的满足感，实际摄入的热量更少一些。

但「低热量」不等于「随便吃」。具体每天吃多少，见下面的 常见问答。

营养拆解

柚子里到底有什么？把「好处」拆成看得懂的成分

不谈玄学，柚子被认可的价值基本就集中在下面几类成分。

① 维生素 C

参与胶原蛋白合成、抗氧化防御，也帮助铁的吸收。成年人每天需要 100mg 左右，水果是主要来源之一。

一整个柚子的果肉通常能提供可观的维 C，具体取决于品种和新鲜度。

② 膳食纤维

果肉里那些不容易咬断的「筋」和细丝就是纤维。它不被消化吸收，却能让你更饱、排便更顺。

小提示：别把白瓤和细纤维全撕干净，那部分恰恰有价值。

③ 钾

钾是维持体液平衡和正常血压的重要矿物质之一，现代人普遍钠多钾少，多吃蔬果是补钾的常规方式。

肾功能异常者需按医生建议控制钾摄入。

④ 类黄酮（柚皮苷等）

这类成分与柚子的微苦味和清香有关，也是植物自身用来抵御外界伤害的物质，被广泛研究其抗氧化等生理作用。

注意：这类成分也会参与药物代谢，服药人群务必看后面的用药提醒。

⑤ 高水分、低能量密度

同样吃饱腹感，柚子带给你的热量更低。控体重的人把它当代替甜点和饮料的选择，比硬忍更可持续。

⑥ 花青素 / 番茄红素（红心柚）

红心柚的粉红色来自番茄红素、β-胡萝卜素等天然色素，颜色好看，也是抗氧化物质的来源之一。

但维 C 含量未必比白柚高，别为颜色多付太多溢价。

一句话总结

柚子是一款「低负担、高水分、有纤维」的日常水果， 适合代替高糖零食和含糖饮料；它是均衡饮食里的一个加分项， 不是包治百病的主角。

🔎 微量元素专题

硒：被低估的必需微量元素，
它在你身体里干的活，比你想的多

硒（Se）是人体必需的微量元素，需要量很小，但一旦长期不足，影响的是抗氧化、 甲状腺和免疫这些基础系统。它自己也合成不了，只能从食物里来。

1

抗氧化防线的核心零件

硒是谷胱甘肽过氧化物酶（GPX）、硫氧还蛋白还原酶（TrxR）等抗氧化酶的活性中心成分。 这些酶负责把体内代谢产生的过氧化物清理掉，减轻氧化应激对细胞膜和 DNA 的损伤。

2

甲状腺正常工作的必需条件

把 T4 转化成活性更强的 T3，靠的是含硒的脱碘酶。甲状腺是人体硒浓度最高的器官之一， 所以硒营养状况与甲状腺功能密切相关。

3

免疫与生殖功能

硒参与免疫细胞功能的调节；睾丸和精子中存在多种硒蛋白，与精子形成和活力相关。 这也是为什么备孕人群的膳食指南会把硒列进去。

每天该吃多少硒？（成人参考值）

中国成人推荐摄入量（RNI）60 μg / 天
美国成人推荐膳食供给量（RDA）55 μg / 天
成人可耐受最高摄入量（UL）400 μg / 天

孕期、哺乳期需求略高；有甲状腺疾病或正在服药的人，请以医生意见为准。

吃不够会怎样

在严重缺硒地区，历史上曾出现过与硒缺乏相关的地方性疾病，如克山病（心肌病变）和大骨节病（骨关节病变）。 我国通过改良土壤、膳食干预等措施已大幅控制。

一般人群只要饮食多样，通常不会严重缺硒，但长期单一饮食、极端节食的人需要留意。

吃多了也不行。 硒的安全范围不算宽。长期明显超量可能出现脱发、指甲变脆变形、蒜味口气、胃肠不适等表现。 因此不建议自行长期大剂量服用补硒产品。

划重点：柚子不是补硒主力，这句话必须说清楚。

水果的硒含量普遍偏低，而且同一品种在不同产区能差出好几倍——因为植物里的硒来自土壤。 所以正确的说法是：柚子的价值在维生素 C、膳食纤维、钾和低热量； 硒请从海产品、蛋、动物内脏、坚果里获取。

把两者放在一起讲的意义在于：它们是同一套「日常吃对」逻辑的两端—— 用柚子替代高糖零食，用富硒食物补齐微量元素，两头都做到，才是完整的健康饮食。

这不是「少吃点就没事」的问题，个体差异很大。请把「我常吃柚子」这句话告诉你的医生或药师， 由他们判断是否需要调整。本页内容不构成医疗建议。

挑选 · 保存 · 剥皮

花同样的钱，挑到皮薄肉厚的那一个

五句口诀 + 三个保存技巧 + 一个不脏手的剥法。

挑选：看、掂、摸、闻

看形状：上尖下宽、底部宽而平
这类果形通常皮薄、果肉厚实；整个浑圆偏扁的，皮往往更厚。
掂重量：同样大小选更压手的
重说明水分足、果肉饱满。轻飘飘的多半放久了、失水了。
摸表皮：光滑细腻、有弹性
毛孔细小均匀的更好；表皮粗糙发硬、坑洼多的通常皮厚。
闻香气：有清甜柚香，没有酒味
有发酵味、酒味的说明放久了，别买。
按一按：微微回弹说明新鲜
按下去凹陷不回弹，多半已经失水或内部变质。

保存 & 剥皮

  • 没切开：阴凉通风处可放 1–2 周，别暴晒、别闷在塑料袋里。
  • 想放更久：用纸巾包一层再装保鲜袋冷藏，可存 3–4 周。
  • 已切开：保鲜膜贴面密封冷藏，2–3 天内吃完，避免串味。
  • 放久变甜是正常的：失水后酸感降低，但再久就会干瘪发苦。

不脏手的剥法：顶部切十字 → 沿切口把皮整片撕下 → 分瓣去掉白瓤 → 用刀背沿筋膜划开，果肉整块落下。

吃法灵感

不止是剥开就吃，四种零门槛的吃法

从最省事的到最有仪式感的，挑一个今天就试。

① 冰镇柚子瓣

剥好的果肉冷藏半小时，酸甜感更突出。想更有层次，撒一小撮盐或话梅粉。

最适合：追剧、加班、嘴馋的晚上。

② 柚子蜂蜜茶

果肉加冰糖小火慢煮到透明，晾凉后拌入蜂蜜，冷藏保存；喝的时候取两勺冲温水。

注意：含糖量不低，当甜品而非「养生水」。

③ 柚子鸡丝沙拉

柚子瓣 + 鸡胸肉 + 生菜 + 坚果碎，淋油醋汁。酸甜解腻，还能顺便吃到坚果里的硒。

最适合：减脂期想吃点有味道的。

④ 柚子气泡水

柚子瓣捣出汁 + 无糖苏打水 + 冰块，喜欢的话加两片薄荷。

比含糖饮料清爽得多，也更有自制感。

顺手提醒三件事

  • 榨成汁会丢掉大部分膳食纤维，饱腹感也变差，能直接吃就别榨。
  • 蜂蜜、冰糖都是糖，柚子茶别当水喝。
  • 白瓤和细纤维别全撕掉，那是纤维含量最高的部分。
常见问答

大家最想问的八个问题

点开就能看，答案尽量说人话。

吃柚子能补硒吗？

不能指望它。水果的硒含量普遍很低，而且同一品种在不同产地能差好几倍，因为植物中的硒取决于土壤。

想补硒，走这几条路更靠谱：海产品（金枪鱼、沙丁鱼、虾）、鸡蛋、瘦肉、动物内脏、坚果（巴西坚果一颗就可能含 68–91 μg）。成人每天大约需要 60 μg，最高不超过 400 μg，别盲目吃补剂。

我正在吃药，能吃柚子吗？

这要看你在吃什么药。柚子、西柚（葡萄柚）中的呋喃香豆素类成分会抑制 CYP3A4 酶，可能让部分药物在体内浓度升高，增加不良反应风险，涉及他汀类降脂药、部分降压药与抗心律失常药、部分镇静催眠药、免疫抑制剂等。

最稳妥的做法：把「我常吃柚子」这句话告诉医生或药师，由他们判断。不要自己凭感觉试验。

糖尿病 / 控糖的人能吃吗？

可以少量吃，但不能敞开吃。柚子水分高、升糖相对温和，但依然含果糖和葡萄糖。

建议：一次 100–200g 果肉，放在两餐之间而不是饭后立刻吃；不要喝柚子汁（纤维没了、升糖更快）；把它算进当天的总碳水里，并照常监测血糖。具体量请听你的医生或营养师。

一天吃多少柚子合适？

《中国居民膳食指南》建议成年人每天吃 200–350g 水果，而且果汁不能替代新鲜水果。

如果你今天只吃柚子，200–300g 果肉（大约 3–5 瓣）是常见范围。但更推荐水果换着吃，营养来源才够宽。

红心柚比白心柚更有营养吗？

各有侧重。红心柚的粉红色来自番茄红素、β-胡萝卜素等天然色素，这类抗氧化物质是它的加分项；但维生素 C 含量未必更高。

如果不为颜色多花太多钱，按口味选就行——能坚持吃下去的水果，才是好水果。

柚子放久了为什么变甜？

采后存放时，果实的有机酸会逐渐消耗，水分也会轻微散失，酸感下降，吃起来就觉得更甜。

但这有个限度。放太久会干瘪、发苦，甚至内部变质。阴凉通风 1–2 周是舒适区，冷藏可以更久。

小孩子能吃吗？

可以。把果肉切成小块，注意别让孩子边跑边吃，避免呛到；酸味明显的品种可以少量尝试。

另外，不建议给 1 岁以下婴儿喝任何果汁，包括柚子汁；这个年龄段以母乳/配方奶和辅食为主。

柚子皮的苦味是什么？能干嘛？

苦味主要来自柚皮苷等类黄酮，以及柠檬苦素类物质，集中在白瓤和皮层。这也是柚子清香味的来源。

常见用法：做柚子茶（皮切细丝焯水去苦后与果肉同煮）、晒干做除味包、擦洗油腻的灶台。需要注意的是，皮上可能有蜡或农残，食用前请用盐或小苏打仔细搓洗。
